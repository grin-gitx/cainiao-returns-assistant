# 菜鸟销退单助手

源码：[GitHub 项目](https://github.com/grin-gitx/cainiao-returns-assistant)。安装与更新使用以下固定地址：

- 脚本安装地址：https://raw.githubusercontent.com/grin-gitx/cainiao-returns-assistant/main/cainiao-returns.user.js
- 更新信息地址：https://raw.githubusercontent.com/grin-gitx/cainiao-returns-assistant/main/cainiao-returns.meta.js

## 安装与使用

1. 在 Chrome 安装 Tampermonkey。
2. 打开脚本安装地址，按提示安装一次。其他电脑也使用同一地址安装。
3. 在菜鸟销退单页面使用三份原始 `.xlsx` 导出文件。
4. 后续在 Tampermonkey 中检查脚本更新。

已有脚本需要迁移时，请在 Tampermonkey 中编辑原脚本并替换为新版本内容，保留原脚本身份，以便沿用现有设置。每台电脑的批次进度彼此独立；同一批次不要在多台电脑同时运行。
